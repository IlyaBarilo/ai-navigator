# Работа с ИИ-навигатором

[Описание проекта](../README.md)

## Запуск

Онлайн-версию открывайте из **Deployments → github-pages** репозитория после успешной публикации. Автономный `ai-navigator.html` доступен в **Releases** после выпуска версии; его также можно [собрать из исходников](DEVELOPMENT.md#сборка). Готовый HTML в Git не хранится.

## Подбор

1. Откройте опубликованный сайт GitHub Pages или собранный/скачанный `ai-navigator.html`. Первым появляется Простой режим.
2. Напишите задачу: «тест по физике для 7 класса», «изменить изображение» или «создать песню».
3. Выберите условия доступа. Бесплатные онлайн- и локальные варианты можно включить вместе. «Все» показывает также платные варианты.
4. При включённом фильтре РФ известные ограничения скрыты. Неподтверждённая доступность остаётся с отметкой «доступ уточнить».
5. Сравните возможности. Откройте подробности и источник условий перед переходом к сервису.

Оценки относятся к конкретной возможности и конфигурации. Пять звёзд у одной функции не обещают такого же качества у остальных. Локальное приложение может требовать установки, загрузки модели и мощной игровой видеокарты.

В Эксперте доступны типовые задачи, пороги качества и сложности, сортировка и подробные карточки. Несколько значений внутри одной группы расширяют выбор; разные условия применяются совместно. Кнопка «Подбор» возвращает в Простой режим.

На телефоне в Простом режиме робот-помощник показывает, где ввести задачу, выбрать доступность и посмотреть результаты. Возле ввода он располагается над полем, поверх страницы, без дополнительных отступов. Если ничего не найдено, он предлагает дополнить описание. Если нужный блок вне экрана, помощник просит прокрутить страницу. В конце он предлагает обучение работе с ИИ-чатами.

По умолчанию подсказки отключены. Кнопка со значком робота рядом с темой включает и отключает помощника; выбранное состояние запоминается. Его также можно отключить маленьким крестиком рядом с персонажем. При нехватке места у кнопки «Аа» скрывается процент; текущий размер остаётся в подсказке и доступном названии кнопки.

## Первый запрос

1. **Урок.** Выберите предмет, класс, тему и вид задания. Пустые поля используют готовый пример.
2. **Запрос.** Прочитайте и при необходимости измените подготовленный текст.
3. **Чат.** Скопируйте запрос и откройте выбранный сервис. Вставьте текст в настоящий чат и отправьте самостоятельно. Учебная схема внутри навигатора не является работающим чатом.
4. **Диалог.** Вернитесь в навигатор и выберите уточнение для улучшения ответа.
5. **Проверка.** Сверьте содержание, соответствие учебной цели и корректность материалов. Отметьте пункты самопроверки и завершите практику.

Ожидаемый результат: собственный отредактированный запрос, ответ выбранного сервиса и решение о пригодности материала после проверки. Навигатор не оценивает внешний ответ автоматически.

## Настройки и обновление

Тема, масштаб, включение помощника, условия подбора и прогресс запоминаются в локальном хранилище браузера (`localStorage`), если оно доступно. Полный изменённый учебный запрос не записывается в постоянное хранилище: сохраните нужный текст перед закрытием страницы.

При обычном открытии появляется Простой режим. Ссылки с явно заданным режимом могут открывать Эксперт или обучение.

Для обновления скачайте новый HTML, сохраните важные запросы, закройте прежнюю вкладку и откройте новый файл. При смене пути или браузера сохранённые настройки могут оказаться недоступны; файл продолжит работать.

## Если возникло затруднение

| Ситуация | Что сделать |
|---|---|
| Открылись исходники GitHub | Перейдите на сайт из Deployments → github-pages. Готовый автономный HTML можно получить из Releases после выпуска или собрать из исходников |
| Ничего не найдено | Упростите запрос, снизьте порог качества или ослабьте условия |
| Копирование не сработало | Текст выделится; нажмите Ctrl+C, ⌘+C или выберите «Копировать» в меню устройства |
| Сервис просит вход | Следуйте инструкции сервиса; навигатор не выполняет вход за вас |
| Сервис не открывается | Вернитесь и выберите другой подходящий сервис |
| Не подходит размер текста | Нажимайте кнопку размера: 100%, 120%, 150%, 50%, 75% |
| После редактирования HTML показана ошибка данных | Проверьте JSON: кавычки, запятые и структуру; см. [документацию разработчика](DEVELOPMENT.md) |

Для вопросов используйте [контакт автора](https://vk.ru/id4022887). При ошибке полезно описать действия, ожидаемый и фактический результат, браузер и способ открытия файла, если они известны.

## Ссылка на обучение

[Начать с обучения](https://ilyabarilo.github.io/ai-navigator/?view=first). Параметр `?view=first` сразу открывает учебный режим; сохранённый прогресс остаётся. Ссылки `#view=first` и `#first-request` также работают. Явный режим или фильтры в якоре имеют приоритет над параметром адреса; без указания режима программа открывает Простой подбор.
